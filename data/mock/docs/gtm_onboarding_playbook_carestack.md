# Customer Onboarding Playbook — CareStack

**Owner:** GTM Customer Success | **Last verified:** 2026-03-02 | **Access tier:** team_restricted_gtm

## Kickoff (Week 1)

- Confirm CareStack API credentials with customer's IT/practice manager.
- Run a test batch of 20 patients through the portal-automation path before going live on full volume.
- Assign a dedicated QA specialist for the customer's first 30 days (see Ops handoff notes).

## Common CareStack-specific issues

- CareStack's sandbox environment occasionally desyncs from production — always confirm the customer has switched us to their production credentials before go-live, not sandbox.
- Multi-location CareStack accounts sometimes have per-location API keys rather than one account-wide key — check this during kickoff, not after go-live.

## Go-live checklist

1. Test batch reviewed and signed off by QA
2. Customer's front-desk staff walked through the new workflow
3. Escalation contact confirmed on both sides
4. First full week monitored daily by CS, not just Ops
